# 📚 ONLINE_BOOK_STORE – SQL Data Analysis Project

## 📌 Project Overview

The **Online Book Store** is a SQL-based data analysis project designed to practice SQL queries and solve business-related problems.

This project focuses on analyzing books, customers, orders, sales, revenue, and inventory using SQL.

## 🎯 Project Objectives

- Analyze book information and genres.
- Retrieve customer and order details.
- Calculate total sales and revenue.
- Identify popular and expensive books.
- Analyze customer purchasing behavior.
- Track available and remaining stock.

## 🛠️ Tools & Technologies

- MySQL
- MySQL Workbench
- SQL

## 📊 Project Tasks

### 1. Basic SQL Queries (11 Questions)

- Retrieve books by genre.
- Find books published after 1950.
- List customers from Canada.
- Retrieve orders placed in November 2023.
- Calculate total available stock.
- Find the most expensive book.
- Identify customers ordering more than one quantity.
- Retrieve orders exceeding $20.
- List available book genres.
- Find the book with the lowest stock.
- Calculate total revenue.

### 2. Advanced SQL Queries (9 Questions)

- Calculate total books sold for each genre.
- Find the average price of Fantasy books.
- Identify customers who placed at least two orders.
- Find the most frequently ordered book.
- Retrieve the top three most expensive Fantasy books.
- Calculate books sold by each author.
- Find cities where customers spending over $30 are located.
- Identify the highest-spending customer.
- Calculate remaining stock after fulfilling orders.
